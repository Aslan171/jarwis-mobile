Три действия

  1. 01Установи APK

    Android попросит разрешить установку из браузера только в первый раз.

  2. 02Запусти Jarwis на ПК

    Открой start_jarwis_mobile.cmd и оставь компьютер включённым.

  3. 03Введи код

    Приложение найдёт ПК в Wi-Fi сети и покажет защищённое сопряжение.
